# Skills

Selected skills for recurring work on AXTON. Follow the linked upstream instructions alongside the repository's [engineering](../engineering/README.md) and [writing](../writing/README.md) guidance.

## Engineering

### Design and planning

- [brainstorming](https://github.com/obra/superpowers/tree/main/skills/brainstorming) — Clarify requirements and design choices.
- [writing-plans](https://github.com/obra/superpowers/tree/main/skills/writing-plans) — Turn an agreed design into implementation steps.
- [plan-eng-review](https://github.com/garrytan/gstack/tree/main/plan-eng-review) — Review architecture, data flow, edge cases, and test coverage before implementation.

### Development and debugging

- [rust-best-practices](https://github.com/apollographql/skills/tree/main/skills/rust-best-practices) — Apollo's guidance on Rust ownership, errors, performance, and API design.
- [systematic-debugging](https://github.com/obra/superpowers/tree/main/skills/systematic-debugging) — Reproduce failures and identify their cause before fixing them.

### Testing and verification

- [test-driven-development](https://github.com/obra/superpowers/tree/main/skills/test-driven-development) — Develop behavior changes through failing tests, implementation, and refactoring.
- [property-based-testing](https://github.com/trailofbits/skills/tree/main/plugins/property-based-testing) — Trail of Bits' guidance on generated tests for serialization, normalization, and invariants.
- [verification-before-completion](https://github.com/obra/superpowers/tree/main/skills/verification-before-completion) — Check results before reporting completion.

### Code review

- [requesting-code-review](https://github.com/obra/superpowers/tree/main/skills/requesting-code-review) / [receiving-code-review](https://github.com/obra/superpowers/tree/main/skills/receiving-code-review) — Review changes and evaluate feedback.

### Documentation

- [doc-coauthoring](https://github.com/anthropics/skills/tree/main/skills/doc-coauthoring) — Structure and refine technical specifications, proposals, and decision documents.
- [document-release](https://github.com/garrytan/gstack/tree/main/document-release) — Update documentation to match shipped changes and identify coverage gaps.
- [document-generate](https://github.com/garrytan/gstack/tree/main/document-generate) — Write missing tutorials, how-to guides, reference, and explanations from the codebase.

### Developer experience

- [plan-devex-review](https://github.com/garrytan/gstack/tree/main/plan-devex-review) — Review API, SDK, and onboarding plans for developer friction.
- [devex-review](https://github.com/garrytan/gstack/tree/main/devex-review) — Walk through documentation and setup to evaluate the actual developer experience.

### Git workflow

- [using-git-worktrees](https://github.com/obra/superpowers/tree/main/skills/using-git-worktrees) — Isolate changes from the main checkout.
