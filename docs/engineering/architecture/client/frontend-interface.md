# Frontend interface

## 1. Introduction and Goals

Open supplies a path, schema and one Stream; an optional connection starts networking after local admission. Rust creates the durable Store identity. Transactions commit local reads and named Mutations locally together, while the Mutations' backend fates remain independent. Query/Fetch are finite fresh reads with boolean storage policy; Bootstrap awaits complete finite coverage.
