# Storage and persistence

Verify real transaction, lock, durability and adapter boundaries. [Server persistence](../../architecture/server/persistence.md) owns the Host contract; [Client storage](../../architecture/client/storage/README.md) owns file admission and local state.

| Requirement | Inspected assertions | Environment/limit |
| --- | --- | --- |
| Readers see committed rows; writers see their own; savepoints roll back independently. | [store.rs](../../../../crates/sqlite/tests/store.rs) checks outside-reader visibility, nested savepoints, query write refusal and conflicting immediate writers. | Real SQLite, no arbitrary power failure. |
| Retired files remain intact on refusal. | [stream_upgrade.rs](../../../../crates/sqlite/tests/stream_upgrade.rs) compares stored catalog/rows and database bytes. | Active negative admission. |
| Batch members commit independently; saved retries rerun neither Handler nor preparation. | [protocol-v05-batch.test.mjs](../../../../integration/persistence/server/protocol-v05-batch.test.mjs) asserts partial progress, saved results, concurrent duplicate equality and Handler/Loader/preparation counters. | Native server and PostgreSQL. |
| Delivery reads current cursor pages, preserves complete components and refuses capacity without response writes. | [protocol-v05-delivery.test.mjs](../../../../integration/persistence/server/protocol-v05-delivery.test.mjs) checks moved versions, removals, absent payload tables, cursor pagination, null-cursor Fetch, owned Remove, uniqueness units and preparation/head order. | PostgreSQL/SDK; joined client capacity is a separate gate. |
| Retained Fetch separates requested projection from current cache and never enrolls. | [retained-fetch.test.mjs](../../../../integration/persistence/server/retained-fetch.test.mjs) checks Loader versions, null cache cursor and zero framework holding/binding changes on malformed projection. | Native server with PostgreSQL. |
| Tracking, targeted invalidation, absence and Loader failure retain their publication semantics. | [publication-semantics.test.mjs](../../../../integration/persistence/server/publication-semantics.test.mjs) checks rows/heads, [] targeting, declaration order, holder preservation and failure without fabricated absence. | PostgreSQL, viewer-dependent Loader. |
| Caller savepoint rollback preserves earlier cursor reservation and caller owns wake. | [publication-savepoint.test.mjs](../../../../integration/persistence/server/publication-savepoint.test.mjs) checks heads/member rows, wake counts and namespace separation. | pg, Prisma and Drizzle driver matrix. |
| Ordinary reads do not hold publication/Store locks while application work waits. | [read-liveness.test.mjs](../../../../integration/persistence/server/read-liveness.test.mjs) checks concurrent write acceptance and later read result; owner/Stream mismatches execute no application work. | Driver matrix; not a universal latency guarantee. |
| Namespace admission and mixed-key guards preserve canonical locks. | [namespace-and-locks.test.mjs](../../../../integration/persistence/server/namespace-and-locks.test.mjs) checks unchanged refused layouts, equivalent DDL catalogs and observed blocked locks. | PostgreSQL adapter. |
| Bulk Host responses preserve caller order and bounded SQL round trips. | [persistence-batching.test.mjs](../../../../integration/persistence/server/persistence-batching.test.mjs) checks 2055 identities, <=4 guard/read/target queries, <=6 published-member queries, duplicates/missing/remove positions and MVCC conflicts. | pg; explicit Prisma default interactive transaction case also bounds total queries. |

Commands/prerequisites: [Running tests](../running.md) and [server runner](../../../../integration/persistence/server/run.sh). The [joined host/capacity gates](../../protocol5-adoption.md) remain release evidence.
