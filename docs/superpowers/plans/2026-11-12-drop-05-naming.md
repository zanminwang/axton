## How a rename commit is made

Save the task's map rows as `map.tsv` (`old<TAB>new`) and its path moves as `moves.tsv` (`from<TAB>to`), outside the repository. A map row is an identifier and is matched as a whole word; a row starting with `re:` is a Perl pattern used as written. Rows apply in order.

```bash
X=(':!docs/engineering/history' ':!docs/superpowers' ':!CHANGELOG.md' ':!integration/performance/baselines' ':!*.lock' ':!package-lock.json' ':!**/package-lock.json')
while IFS=$'\t' read -r old new; do
  case "$old" in re:*) pat="${old#re:}";; *) pat="\\b\\Q$old\\E\\b";; esac
  { git grep -lzP "$pat" -- "${X[@]}" || echo "no match: $old" >&2; } | xargs -0 perl -pi -e "s/${pat//\//\\/}/${new//\//\\/}/g"
done < "$MAP"
while IFS=$'\t' read -r from to; do mkdir -p "$(dirname "$to")" && git mv "$from" "$to"; done < "$MOVES"
cargo fmt --all
node_modules/.bin/prettier --write "packages/frontend/client-js/**/*.mts" "packages/backend/server/**/*.mts" "packages/backend/postgres/**/*.mts" "packages/frontend/client-react-native/**/*.mts"
```

The command applies every row to the whole repository: a block groups names by where they are defined, and their uses elsewhere change in the same commit. Take the Prettier globs from `scripts/test.sh:25` (it also lists two `index.ts` files). Then regenerate (Global constraints) and commit. **Acceptance for each rename commit:** check out its parent, run the same rows, formatters and regeneration, and `git diff <commit>` is empty. Record the rows used in the commit message by task and block name.
